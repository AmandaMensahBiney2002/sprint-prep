# Todo App

I built a simple and interactive Todo App built using HTML, CSS, and JavaScript. This project allows users to create, manage, and organize their daily tasks while practicing fundamental web development concepts.


## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* View and manage daily activities
* Simple and responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Learned

Through this project, I practiced:

* Creating webpage structures using HTML
* Styling pages with CSS
* Using JavaScript to add interactivity
* Working with buttons, events, and user input
* Manipulating webpage elements using the DOM

## How to Run the Project

1. Clone this repository:

```
git clone https://github.com/AmandaMensahBiney2002/todo-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
